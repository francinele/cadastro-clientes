# Sistema de Cadastro de Clientes

Este é um projeto de cadastro de clientes que desenvolvi para praticar Python, criação de interfaces gráficas e banco de dados.

O sistema permite cadastrar, pesquisar, editar e excluir clientes. As informações ficam armazenadas localmente em um banco de dados SQLite.

## Funcionalidades

- Cadastro de nome, e-mail e telefone
- Validação do e-mail
- Formatação do telefone
- Pesquisa por nome ou e-mail
- Edição de cadastros
- Exclusão com confirmação
- Registro automático da data e hora do cadastro
- Armazenamento dos dados em SQLite

## Tecnologias utilizadas

- Python
- Tkinter
- SQLite

## Como executar

1. Instale o Python no computador.
2. Baixe os arquivos deste repositório.
3. Abra a pasta do projeto no terminal.
4. Execute o comando:

```bash
py interface.py
```

Se o comando anterior não funcionar, tente:

```bash
python interface.py
```

Não é necessário instalar bibliotecas externas, pois o projeto utiliza recursos que já acompanham o Python.

## O que aprendi

Durante o desenvolvimento, pratiquei a criação de uma interface com Tkinter, a integração com o banco SQLite, a validação de dados e as operações de cadastrar, consultar, editar e excluir registros.

Também aprendi a organizar melhor o código, reduzir repetições e separar as funções de acordo com suas responsabilidades.
